# MediFlow Modules

This directory will contain feature modules for the MediFlow API.

## Planned Modules

Each module follows a consistent structure:

```
modules/
├── auth/
│   ├── auth.controller.ts
│   ├── auth.service.ts
│   ├── auth.routes.ts
│   └── auth.schema.ts        (Zod validation schemas)
├── users/
├── organizations/
├── patients/
├── providers/
├── claims/
├── payments/
├── tasks/
└── appointments/
```

> Modules will be added in Step 2 of the MediFlow backend setup.
